# Homebrew Tap Repository Setup

This guide walks through setting up a Homebrew tap repository for mcp-manager.

## What is a Homebrew Tap?

A Homebrew "tap" is a third-party repository containing formula files that tell Homebrew how to install software. Users can add your tap to install your software with simple commands like `brew install mcp-manager`.

## Repository Setup

### 1. Create the Tap Repository

The tap repository must follow Homebrew's naming convention: `homebrew-{package-name}`

```bash
# Create repository on GitHub: ihavespoons/homebrew-mcp-manager
# Then clone it locally:
mkdir homebrew-mcp-manager
cd homebrew-mcp-manager
git init
```

### 2. Create Directory Structure

```bash
mkdir Formula
```

The repository structure will be:
```
homebrew-mcp-manager/
├── README.md
└── Formula/
    └── mcp-manager.rb  (auto-generated by CI)
```

### 3. Create README.md

```bash
cat > README.md <<'EOF'
# Homebrew Tap for mcp-manager

Official Homebrew tap for [mcp-manager](https://github.com/ihavespoons/mcp-manager) - MCP server manager with Docker support.

## Installation

```bash
brew tap ihavespoons/mcp-manager
brew install mcp-manager
```

## Updating

```bash
brew upgrade mcp-manager
```

## Uninstall

```bash
brew uninstall mcp-manager
brew untap ihavespoons/mcp-manager
```

## About

This tap is automatically updated by [GitHub Actions](https://github.com/ihavespoons/mcp-manager/actions) when new releases are published.

The formula is generated from the release workflow and includes:
- Multi-platform support (macOS Intel, macOS Apple Silicon, Linux AMD64, Linux ARM64)
- SHA256 checksums for security
- Automatic version updates

## Manual Installation

If you prefer to install without tapping:

```bash
brew install ihavespoons/mcp-manager/mcp-manager
```

## Issues

For issues with the package itself, please report them in the [main repository](https://github.com/ihavespoons/mcp-manager/issues).
For issues with the Homebrew formula, please also report in the main repository with the `homebrew` label.
EOF
```

### 4. Initial Commit and Push

```bash
git add README.md Formula/
git commit -m "Initial tap repository setup"
git branch -M main
git remote add origin https://github.com/ihavespoons/homebrew-mcp-manager.git
git push -u origin main
```

## GitHub Token Setup

The release workflow needs a token to update the tap repository automatically.

### 1. Create Personal Access Token

1. Go to GitHub Settings → Developer settings → Personal access tokens → Tokens (classic)
2. Click "Generate new token (classic)"
3. Give it a descriptive name: `mcp-manager-homebrew-tap-updater`
4. Select expiration (recommendation: 1 year, then rotate)
5. Select scopes:
   - ✅ `repo` (Full control of private repositories)
     - This includes: `repo:status`, `repo_deployment`, `public_repo`, `repo:invite`, `security_events`

6. Click "Generate token"
7. **Copy the token immediately** (you won't see it again!)

### 2. Add Token to Main Repository

1. Go to the **main repository** (ihavespoons/mcp-manager)
2. Settings → Secrets and variables → Actions
3. Click "New repository secret"
4. Name: `HOMEBREW_TAP_TOKEN`
5. Value: Paste the token from step 1
6. Click "Add secret"

## Testing the Automation

### Before First Release

1. Ensure the tap repository exists: https://github.com/ihavespoons/homebrew-mcp-manager
2. Ensure the token is configured in the main repository secrets
3. The Formula directory should be empty (formula will be auto-generated)

### First Release

1. In the main repository, create and push a tag:
   ```bash
   git tag -a v0.1.0 -m "Release v0.1.0"
   git push origin v0.1.0
   ```

2. Watch GitHub Actions:
   - Go to Actions tab in main repository
   - Watch the "Release" workflow run
   - All jobs should complete: Build → Release → Update Homebrew

3. Verify tap repository:
   - Check homebrew-mcp-manager repository
   - Should have a new commit: "Update mcp-manager to v0.1.0"
   - `Formula/mcp-manager.rb` should exist with correct version and checksums

### Testing Installation

```bash
# Add the tap
brew tap ihavespoons/mcp-manager

# Install the package
brew install mcp-manager

# Verify installation
mcp-manager --version
# Should output: mcp-manager version 0.1.0 (commit: ..., built: ...)

# Test functionality
mcp-manager validate --config ~/.config/mcp-manager/mcp-config.yaml

# Clean up (if testing)
brew uninstall mcp-manager
brew untap ihavespoons/mcp-manager
```

## Troubleshooting

### Token Issues

**Problem**: Workflow fails with "Authentication failed"
- Check token is still valid (not expired)
- Check token has `repo` scope
- Regenerate token if needed and update secret

**Problem**: Workflow fails with "Repository not found"
- Verify tap repository name: `ihavespoons/homebrew-mcp-manager`
- Check token has access to the tap repository
- Ensure tap repository is public or token has access to private repos

### Formula Issues

**Problem**: Formula has wrong checksums
- This would only happen if release artifacts were modified after checksums were calculated
- Delete the release, fix the issue, create new release with new version

**Problem**: Formula fails to install
1. Test the download URLs manually:
   ```bash
   curl -L -o test.tar.gz "https://github.com/ihavespoons/mcp-manager/releases/download/v0.1.0/mcp-manager-v0.1.0-darwin-arm64.tar.gz"
   tar -tzf test.tar.gz
   ```
2. Check the binary is named correctly: `mcp-manager`
3. Check file permissions in archive
4. Test extraction and execution locally

**Problem**: "Checksum mismatch" error
- Archives were modified after release
- Need to create a new release with incremented version

### Workflow Issues

**Problem**: Update Homebrew job fails
- Check workflow logs for specific error
- Common issues:
  - Git config not set (should be set by workflow)
  - Push permission denied (check token)
  - Nothing to commit (formula unchanged - not an error)

## Maintenance

### Token Rotation

Tokens should be rotated regularly (every 6-12 months):

1. Create new token with same permissions
2. Update `HOMEBREW_TAP_TOKEN` secret in main repository
3. Test with a new release
4. Revoke old token once confirmed working

### Formula Updates

The formula is automatically updated on every release. No manual maintenance required unless:
- Changing installation logic
- Adding dependencies
- Modifying test commands

For manual formula updates, edit `Formula/mcp-manager.rb` in the tap repository.

### Monitoring

Set up GitHub notifications for:
- Failed workflow runs in main repository
- Issues opened in tap repository
- Security alerts for either repository

## Advanced Configuration

### Caveats

Add usage notes that display after installation:

```ruby
# In Formula/mcp-manager.rb
def caveats
  <<~EOS
    To get started, create a configuration file:
      mkdir -p ~/.config/mcp-manager
      mcp-manager init > ~/.config/mcp-manager/mcp-config.yaml

    Register with Claude Code:
      mcp-manager register

    Start the server manager:
      mcp-manager serve
  EOS
end
```

### Dependencies

If mcp-manager requires other software:

```ruby
depends_on "docker" => :recommended
depends_on "go" => :build  # only needed during build
```

### Service Management

For running as a background service:

```ruby
service do
  run [opt_bin/"mcp-manager", "serve", "--config", "#{etc}/mcp-manager/config.yaml"]
  keep_alive true
  log_path var/"log/mcp-manager/stdout.log"
  error_log_path var/"log/mcp-manager/stderr.log"
end
```

Then users can:
```bash
brew services start mcp-manager
brew services stop mcp-manager
```
